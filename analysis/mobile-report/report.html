Important limitation

This is a name-pattern signal only. It does not establish nationality, citizenship, ethnicity, ancestry, or identity. A row is retained only when one given-name token and one surname token match the Turkish population corpus after exact ASCII normalization, so both false positives and false negatives remain possible.
